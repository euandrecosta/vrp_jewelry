# vRP Jewelry

> Early Project / Legacy Repository

This project is part of my early programming journey. It is preserved as a record of my technical evolution and does not represent my current coding standards.

## About

Jewelry store robbery system originally developed for a
vRP-based FiveM server.

## Features

- Security camera hacking flow
- Jewelry showcase robbery interactions
- Character animations
- Particle and sound effects
- Showcase model swapping
- Randomized stolen items
- Robbery cooldowns
- Server-side reward handling

## Tech Stack

- Lua
- FiveM
- vRP
- GTA V natives
